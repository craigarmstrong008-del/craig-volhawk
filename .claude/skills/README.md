# Project skills

Playbooks Claude Code loads automatically in this repo. Each one summarizes an external open-source
agent tool: what it does, how to install it, its main commands, and the guardrails to follow.

| Skill | Tool | Use it for |
|---|---|---|
| `career-ops` | career-ops-hq/career-ops | Scoring jobs against your CV, tailored resumes, application tracking |
| `agent-reach` | Panniantong/Agent-Reach | Reading YouTube, Reddit, GitHub, LinkedIn and the web |
| `officecli` | iOfficeAI/OfficeCLI | Creating and editing Word, Excel and PowerPoint files without Office |
| `hypit` | hypit-ai/hypit | Turning a video's format into an editable workflow you can reuse |
| `website-cloner` | JCodesMore/ai-website-cloner-template | Rebuilding a site you own as a Next.js app |
| `strix` | usestrix/strix | Authorized AI pentesting of your own apps |
| `paperclip` | paperclipai/paperclip | Running a team of AI agents with an org chart, budgets and approvals |

Notes reflect the upstream READMEs as of 2026-11-04. Check upstream before relying on exact flags.
